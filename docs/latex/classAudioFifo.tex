\doxysubsection{Detailed Description}
Thread-\/safe FIFO queue for audio blocks. 

\doxylink{classAudioFifo}{Audio\+Fifo} stores timestamped audio blocks (capture time + samples). It is intended for producer/consumer use, for example one thread recording audio and another thread playing it back.
