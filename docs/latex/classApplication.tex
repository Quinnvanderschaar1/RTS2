\doxysubsection{Detailed Description}
Main conferencing application controller. 

The \doxylink{classApplication}{Application} class owns the high-\/level runtime flow of the program\+: audio configuration, startup logging, device/simulation setup, thread creation, thread joining, and shutdown cleanup.
