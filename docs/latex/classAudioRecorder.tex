\doxysubsection{Detailed Description}
Audio recording class using Port\+Audio. 

\doxylink{classAudioRecorder}{Audio\+Recorder} continuously captures audio from the default input device and pushes 10 ms audio blocks into an \doxylink{classAudioFifo}{Audio\+Fifo}.
